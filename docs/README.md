# Get-On docs

- `ui-spec.md` - the UI specification v1 (single source of truth for the product UI).
- `screenshots/` - captured screens (360/768/1280 px, light and dark) generated with `pnpm screenshots` from the repo root.
- `admin.md` - staff roles, the privacy boundary and the admin console.
- `ui-spec-admin.md` - the admin and email screens.
- `email-system.md` - streams, outbox, consent, delivery events and jobs.
- `marketing-email.md` - opt-in campaigns, segments, limits and operations.
- `approvals.md` - four-eyes requests, policy thresholds and execution.
- `support-cases.md` - cases, notes, SLA and support screens.
- `reports.md` - report snapshots, finance months and the weekly report.
- `ses-setup.md` - Amazon SES, SNS and Supabase Auth SMTP.
