## (b) Google tag Consent Mode v2 settings

### gtag configuration parameters for privacy:
- `send_page_view` - control whether pageview is sent automatically
- `allow_google_signals` - whether to allow Google signals (remarketing, etc.)
- `allow_ad_personalization_signals` - whether to allow ad personalization
- Cookie flags: `cookie_expires`, `cookie_domain`
- `page_location` overrides

### Enhanced Measurement features:
- Can only be disabled in the GA property (not via gtag config)
- Features: scroll, outbound, exit, download, playback, connect, ad_demand
- Need to review which are enabled and if they should be disabled

### Consent Mode v2 defaults:
- Default state: denied (nothing sent until consent)
- Global Privacy Control and Do Not Track = declined

## (c) Next.js App Router way to load scripts with CSP nonce and route grouping

### Loading scripts with nonce:
- Next.js App Router supports `<Script>` component with `strategy="afterInteractions"` or `onLoad`
- CSP nonce generated by Next.js and passed to script tags
- Can scope scripts to route groups using `next/script` in `(marketing)` group

### Route group scoping:
- Next.js route groups `(...)` allow grouping routes without affecting URL
- Can create `(marketing)` group for pages that allow analytics
- Script loading conditional on route group membership
