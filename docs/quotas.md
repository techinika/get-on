# Quotas

This document is generated by the audit for team quotas. Every limit check must go through `lib/quotas.ts` / `team_quota_usage()` and exclude deleted websites.

## Sources of truth
- `plans` table (limits)
- `team_quota_usage(p_team uuid)` (single source)
- `lib/quotas.ts` helpers

## What counts
- Active websites: `projects.deleted_at IS NULL`
- Pages: visible pages of non-deleted websites
- Plugins/domains/storage: for non-deleted websites
- Members: active members only (paused do not count)
- Pending invitations: count toward seats
- Deleted pending: `projects.deleted_at IS NOT NULL` (subject to `max_deleted_pending`)

## Rules
- Deleted websites never count toward any quota, never appear in lists/pickers/switcher
- Restore requires room after restoration
- Protection cap per team on deleted pending
- Creation rate limits enforced
